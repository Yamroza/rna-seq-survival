# Cancer Survival Prediction using Transcriptomics Data
This repository contains the code for performing cancer survival prediction using Transcriptomics data. It contains and support the implementation of several deep learning approaches. 

Contact: Aniek Eijpe (a.eijpe@uu.nl)

# Code structure
- `figures` contains all figures explaining the different architectures.
- `src` contains the source code to run the different models for survival prediction using Transcriptomics data. See the README in this folder for more explanation and instructions on how to run the different deep learning models for the task of survival predictions.

# System requirements
To run the code, please use the following code to create the conda environment that is used.
```
cd TS_Survival_Prediction
conda env create -f myenv.yml
conda activate myenv
```
